# Clipboard Cleaner 1.0.0

The first version of Clipboard Cleaner: a small native macOS menu bar app for clearing the active system clipboard on demand.

## Features

- Clear the current system clipboard with **Delete Clipboard**.
- A compact menu bar window with a separate **Close App** button.
- No main window, Dock icon, clipboard monitoring, stored history, analytics, or network requests.
- App Sandbox and Hardened Runtime enabled.
- Universal Release build for Apple Silicon and Intel; macOS 13 Ventura or later.
- App icon included at all standard macOS sizes.

## Launch at login

Automatic launch is optional and configured manually in macOS **Login Items → Open at Login** (under **Login Items & Extensions** on newer macOS versions). The app does not register a login item itself. Remove it from that list to disable automatic launch; **Close App** only quits the current session.

Launching the app does not clear the clipboard. Clearing always requires clicking **Delete Clipboard**.

## Privacy

Only the active system clipboard is cleared. Copies already held by clipboard managers, other apps, or other devices are not guaranteed to be removed. This is not a secure-erasure guarantee.
